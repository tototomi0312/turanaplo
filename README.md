# Túranapló

Hiking diary prototype (PWA): pick a place (OpenStreetMap), record the route with GPS,
then see distance, estimated steps, elevation gain/loss and profile, add photos, a review,
star rating, kid/dog-friendly flags and difficulty. All data stays on the device (IndexedDB).

Data: © OpenStreetMap contributors (Nominatim, Overpass), OpenTopoMap, Waymarked Trails, Open-Meteo elevation.
